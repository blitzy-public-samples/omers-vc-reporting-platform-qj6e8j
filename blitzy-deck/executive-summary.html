Backward compatibility preserved

Compatibility Discipline

  • Pydantic kept on the v1 line (1.10.13) — the BaseSettings API is preserved; no Pydantic v2 migration.
  • FastAPI capped < 0.126.0 (pinned 0.125.0) — retains Pydantic v1 support while clearing CVE-2024-24762.
  • Minimal Change Clause honored — version bumps only; no package replacements; no public-API contract changes.
  • No import statements changed by the dependency upgrades — every upgrade stays within a compatible API line.

Trade-off: because the FastAPI/Pydantic-v1 envelope is frozen, a small set of starlette/click advisories cannot be cleared without breaching it; these remain under documented CI waivers (see next slide).

How the fix was proven

Verification

  • Dependency scan (pip-audit) — the CI gate passes when no un-waived advisory remains; residual starlette/click/python-dotenv advisories (unfixable within the Pydantic-v1 envelope, or whose fix needs Python ≥ 3.10 on the Python 3.9 services) carry documented --ignore-vuln waivers.
  • CORS regression tests — never Access-Control-Allow-Origin: * together with credentials; only configured origins are reflected; unlisted origins are not reflected.
  • Secret-required configuration tests — JWT_SECRET_KEY / SECRET_KEY required and length-enforced (min 32); no "your-secret-key" default resolvable.
  • Secret / IaC scan — no plaintext password literal remains in source; the main.tf credential fix validates in isolation.
  • Container non-root check — built images run as a non-zero uid (id -u → 1000).
  • Regression suites re-run — the security suites pass; a few full-application suites do not yet collect because of pre-existing, documented blockers (see next slide).
Transparency — documented, not concealed

Residual Risk & Deferred Follow-Ups

Full detail lives in SECURITY.md and docs/security/decision-log.md.

Open residual risk

  • Architectural authentication rework Critical — pre-existing gateway bearer-flow inconsistency and business-router authorization gaps; separately authorized work.
  • Residual starlette/click/python-dotenv advisories — unfixable within the frozen FastAPI/Pydantic-v1 envelope, or (on the Python 3.9 services) whose fix needs Python ≥ 3.10; held under documented CI waivers.
  • Former DB credential in git history — removed from the current tree; rotation + approved history purge remain an operational follow-up.
  • Container default startup — images are non-root, but a default docker run needs the namespace packaged for the build context.

Deferred by scope

  • pytest (6.x→9.x, test-only) and loguru upgrades.
  • End-of-life PostgreSQL v11 engine version.
  • Placeholder demo-credential rework (architectural).
  • Broad observability — tracing, Prometheus wiring, App Insights.
  • Dependency lockfiles; data-transformation runtime alignment.
